# Audio Downloader

- **Slug:** `audio-downloader`
- **Sector:** Desktop Software / Audio Utilities
- **Summary:** A lightweight Windows desktop app for downloading MP3 audio from public YouTube videos, playlists, and SoundCloud tracks. Paste one or more links, choose a download folder, and let the app handle the rest.
- **Challenge:** Downloading audio through command-line tools can be awkward for people who want a quick, repeatable workflow, especially when handling several links at once.
- **Approach:** Built a focused desktop interface for batch link input, MP3 downloads, progress feedback, and a user-selected output folder. The app packages its runtime so it can run as a portable Windows executable.
- **Outcome:** A ready-to-run Windows utility that makes single and batch audio downloads accessible through a simple graphical workflow, without requiring users to set up Python.
