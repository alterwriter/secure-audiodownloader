## Audio Downloader for Windows

A portable Windows x64 app for downloading MP3 audio from public YouTube and SoundCloud links.

### Included

- `AudioDownloader.exe` — portable application
- `Install.ps1` — installs per user and adds a Start menu shortcut
- `Uninstall.ps1` — removes the installed app and shortcut
- `README.md` — install and usage instructions
- `THIRD_PARTY_NOTICES.md` — third-party component notices

The release ZIP does not include the Python source code. The installer is a PowerShell script; no separate MSI or setup EXE is included.
